# Dados, Informação, Conhecimento (e Expertise)

## Dados

Menor unidade/fração da informação. São fatos brutos sem qualquer contexto ou significado por si.

São exemplos: 100, "Dado", Verdade, 42

## Informação

Informação é a característica do dado, é o que atribui algum significado e distinção, embora não o transforme em conhecimento.

São exemplos: 100ºC, O objeto "Dado", "Dado" que algo é Verdade, a resposta para a pergunta "Qual é a resposta para a vida, o universo e tudo mais?" é 42.

## Conhecimento

É o que se faz com a informação, é quando se consegue aplicar e interpretar a informação de forma prática.

São exemplos: 100ºC é a temperatura de ebulição da água, o objeto "Dado" é um exemplo de dado, "Dado que hoje é terça", é verdade quando se refere a uma afirmação comprovada, e 42 é a resposta para a pergunta sobre a vida, o universo e tudo mais, segundo Douglas Adams.
